# Cool TUI library

This is a work in progress TUI library that is/aspires to be

## Retained

Not out of disdain for immediate mode, I just felt like it. It
barely even uses advantages of retained mode

## Modular

You can assess your needs and

- Use the whole environment framework with interactivity in mind
- Use it to layout and render an element tree
- Use it to layout text in a box
- Use it solely for minor terminal utilities

## Well-documented

Unfortunately that's not the case as of writing
